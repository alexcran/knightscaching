# GC12345 — Example Cache Directory

This is an example cache directory. Replace `GC12345` with the actual GC code.

Files placed here are publicly accessible at:

  https://knightscaching.com/assets/caches/GC12345/filename.ext

## Suggested contents

- `hint.jpg` — a hint image
- `map.jpg` — a map or area photo
- `description.html` — supplemental HTML for the listing
- Any other files referenced on the geocaching listing page

Create one subdirectory per cache code, e.g.:

  public/assets/caches/
    GC12345/
    GC99ABC/
    GC00XYZ/
